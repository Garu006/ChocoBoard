🍫 ChocoBoard

ChocoBoard es un teclado personalizado para Android diseñado con un enfoque en la estética minimalista y una experiencia de usuario fluida. A diferencia de los teclados estándar, ChocoBoard busca una identidad visual única inspirada en tonos tierra y un diseño de "cristal" redondeado.
🚀 Características actuales

    Motor IME funcional: Implementación completa de InputMethodService.

    Diseño Premium: Teclas con esquinas redondeadas (estilo iOS) y efectos de profundidad.

    Layout QWERTY: Mapa de teclas completo con soporte para caracteres alfabéticos.

    Haptic Feedback: Vibración sutil al presionar las teclas para una experiencia táctil realista.

    Teclas Especiales: Funcionalidad para Borrar (Backspace), Espacio y Enter.

🛠️ Tecnologías utilizadas

    Lenguaje: Java / Kotlin.

    Framework: Android SDK.

    Componentes: KeyboardView, Keyboard, InputConnection.

    Diseño: XML Drawables (Layer-lists, Selectors y Shapes).

⚙️ Instalación

    Clona este repositorio.

    Abre el proyecto en Android Studio (Ladybug o superior).

    Compila e instala en tu dispositivo o emulador.

    Ve a Ajustes > Sistema > Idiomas e introducción > Teclado en pantalla.

    Activa ChocoBoard y selecciónalo como método de entrada predeterminado.
